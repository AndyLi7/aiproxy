## Local proxy DNS

This machine's TUN proxy returns `198.18.0.0/15` Fake-IP answers for fal hosts.
Native artifact downloads correctly reject that range. The local runtime sets
`NATIVE_ARTIFACT_DNS_RESOLVER=cloudflare` to resolve artifact host IPv4 addresses
through the fixed Cloudflare HTTPS DNS endpoint. The request contains only the
hostname. It has a five-second deadline, bounded response and no redirect or
system-DNS fallback. All addresses must pass the existing public-address guard;
TLS verifies the original hostname while dialing a validated address.

Unset or `system` keeps the original resolver behavior. No default or production
API transport was changed. No global resolver or proxy setting was changed.
